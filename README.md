# 智学课堂 · 前端项目 

## 一、项目简介

智学课堂是一个面向高校的在线学习与刷题平台，前端采用 Vue 3 + TypeScript 开发，模拟了完整的用户认证体系与学生端学习场景。本项目当前版本实现了以下核心模块：

- **用户登录模块**：支持多身份登录（学生、教师、管理员）、注册、忘记密码、图形验证码、记住我、登录失败锁定、多端管理模拟等安全策略。
- **学生端工作台**：包含课程中心、课程详情（学习资源/任务/问答/作业考试/小组教学/课堂学习），其中重点实现了视频播放时弹出题目、考试防切屏与倒计时、小组自由组队等复杂交互。

所有数据均在前端模拟（localStorage + Pinia），无需任何后端服务即可完整演示业务流程。

## 三、核心功能模块

### 1. 用户登录模块

- **统一登录入口**：支持用户名/邮箱/手机号 + 密码登录，系统根据账号类型自动重定向到不同首页（学生、教师、管理员）。
- **验证码**：前端随机生成图形验证码，模拟短信验证码（固定 `123456`）。
- **安全策略**：
  - 连续 5 次登录失败锁定账号 30 分钟（前端计时）。
  - 注册/修改密码时强制密码强度（大小写+数字+特殊字符，8~16位）。
  - 密码前端模拟加密（Base64 / 预留 RSA 注释）。
  - 登录成功后生成模拟 JWT，支持“记住我”延长有效期。
  - 主动登出、Token 过期检查（模拟 2 小时）。
- **用户体验**：Tab 键切换焦点、回车提交、加载动画、区分错误提示。

### 2. 学生端页面（登录后）

#### 2.1 课程中心
- 学期筛选 + 课程名搜索。
- 课程卡片网格展示（含进度条），点击卡片放大预览详情，进入课程详情页。

#### 2.2 课程详情页（多 Tab）
- **学习资源**：教学视频 + 文档。**视频弹题**：播放到预设时间点自动暂停并弹出题目，学生作答后继续播放，结束时统计正确率。
- **学习任务**：任务列表（按截止时间排序），支持在线作答、附件上传、提交待批改。
- **问答讨论**：教师发起的讨论主题，学生可回复并获得平时积分（前端模拟）。
- **作业考试**：
  - 客观题实时判分，主观题提交待批阅。
  - 考试模式含倒计时、防切屏（切出超过 3 次自动交卷）、自动交卷。
- **小组教学**：
  - 创建小组（最多 5 人）、搜索其他学生并发送组队申请。
  - 小组共同回答教师问题，教师审核后积分平均分配。
- **课堂学习**：根据 mock 课表突出显示当前时段可进行的活动。

### 3. 未登录首页（占位）
- 顶部导航（Logo、课程、电子教材、学校、题库、刷题、搜索、登录按钮）。
- 轮播图静态占位，课程推荐区域展示 8~12 个静态卡片。
- 其他页面（电子教材、学校等）显示“开发中”。
